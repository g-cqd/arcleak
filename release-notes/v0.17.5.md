# arcleak 0.17.5 (from 0.17.4)

A lifetime token made by a `map` or `compactMap` closure (`observers = names.map { center.addObserver(forName: $0, …) }`) goes where the call's result goes. It was reported as discarded wherever the array went; it is now stored when the array is assigned to a member, discarded when the array is, and stored in a local when the array is bound to one.

## Findings that may appear

- `token-stored-in-local` for a token made by a `map` or `compactMap` closure whose result is bound to a local (0.17.4 reported `unstored-lifetime-token` there).

## Findings that may disappear

- `unstored-lifetime-token` for a token made by a `map` or `compactMap` closure whose result is assigned to a member of the type, or bound to a local (reported as `token-stored-in-local` instead).
